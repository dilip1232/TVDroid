# Security policy

## Supported versions

Only the latest release of TVDroid gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately on GitHub:
[Security → Report a vulnerability](https://github.com/dilip1232/TVDroid/security/advisories/new).

Include the TVDroid version, your macOS version, and the steps to reproduce the problem.
You get an answer within 7 days.

## Scope

- The TVDroid app and its phone remote server (port 8765 on your local network).
- The scripts `setup.sh` and `build.sh`, and the GitHub workflows.

The Android emulator, the Google TV system image, and the APKs that you run are not part of TVDroid.
Report problems in them to Google or to the app developer.
